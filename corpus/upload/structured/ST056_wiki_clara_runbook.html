Common abends

CodeMeaningAction
S0C7Data exception – non-numeric data in a packed or zoned field.Identify the failing key from the dump, hand the record to development; do not patch data in place.
S0C4Protection exception – invalid storage reference.Collect the dump and escalate to the on-call developer.
S322CPU time limit exceeded.Check for unusual volumes before rerunning; escalate if it repeats.
S806Load module not found.Check the load library concatenation and the last promotion.
SB37 / SD37Dataset out of space.Allocate more space through the storage team, then restart the step.
SQLCODE -911DB2 deadlock or timeout.Rerun the step once; if it fails again, check for long-running units of work.
SQLCODE -805DBRM or package not found.Check the last bind for the program and escalate to the DBA.

Shift checklist

  • If the same step fails twice, stop and escalate; repeated reruns make diagnosis harder.
  • Do not cancel a job that is waiting on a dataset enqueue without consulting the on-call developer.
  • Before restarting, confirm with the Batch Scheduler that no dependent job has started.
  • Check the job log for the first abend message rather than the last one.
  • Restarts outside the batch window need the agreement of the CLARA platform on-call lead.
  • After a successful rerun, check the downstream trigger datasets were created.
  • Data fixes are never applied directly in production tables; raise a change.
  • Record every manual action in the shift log with the time and the operator ID.
