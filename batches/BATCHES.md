## How to upload

1. Run `.venv/bin/python -I harness/make_batches.py --materialize`. It creates `batches/materialized/order_A/batch_01/` and so on: one folder per batch, holding hard links to the corpus files.
2. Use a new, empty context for each order. Upload order A's batches into one context and order B's into another, in batch-number order.
3. For each batch, drag the batch folder's files into the product's upload dialog. Wait until ingestion of the whole batch has finished before you start the next batch.
4. Record each batch's start and finish time, and any file that failed or was flagged.
