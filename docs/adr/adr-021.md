# ADR-021: Idempotency keys for all payment instructions

- Status: Accepted
- Date: 2026-09-16
- Deciders: Linnea Sjöberg (Engineering Lead – Fraud & Settlement Squad), Elin Fosse (Lead Solution Architect)
- Forum: Design Authority
- Supersedes: none
- Superseded by: none

## Context

INC-2026-0914: duplicate payment instructions were sent on the Wave 1 cut-over because payment-orchestrator retried after a Corvane Payments Gateway timeout without an idempotency key.

## Decision

Every payment instruction sent to the Corvane Payments Gateway carries an idempotency key.

## Consequences

Introduced after INC-2026-0914.

## Notes

Implementation details live in the service repositories and are not repeated here.
