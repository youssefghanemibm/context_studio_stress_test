# ADR-011: Reserve calculations owned by a single reserve service

- Status: Accepted
- Date: 2025-04-14
- Deciders: Nadia Petrovic (Java Technical Lead), Daniel Achebe (Engineering Lead – Reserve & Finance Squad)
- Forum: Design Authority
- Supersedes: none
- Superseded by: none

## Context

Several CLARA programs write to the reserve table, which makes reserve changes hard to audit.

## Decision

In Claims Hub only the reserve service writes reserves; every other service requests a reserve movement through its API.

## Consequences

Only reserve-engine (then reserve-svc) writes reserves in Claims Hub.

## Notes

Implementation details live in the service repositories and are not repeated here.
