# ADR-013: Synchronous REST scoring with Sentinel

- Status: Accepted
- Date: 2025-05-05
- Deciders: Elin Fosse (Lead Solution Architect), Oskar Lindgren (Senior Fraud Analyst)
- Forum: Design Authority
- Supersedes: none
- Superseded by: none

## Context

Fraud scores are needed at triage time, and Sentinel offers a synchronous REST scoring API.

## Decision

Call Sentinel synchronously over REST from triage-svc.

## Consequences

Timeout 800 ms; fall back to batch scoring.

## Notes

Implementation details live in the service repositories and are not repeated here.
