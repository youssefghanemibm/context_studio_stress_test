# ADR-018: Tier calculation as a shared library

- Status: Deprecated
- Date: 2025-07-07
- Deciders: Nadia Petrovic (Java Technical Lead)
- Forum: Design Authority
- Supersedes: none
- Superseded by: ADR-030

## Context

Several services needed the claim tier and were each re-implementing BR-TRI-003.

## Decision

Publish the tier calculation as a shared Java library.

## Consequences

Deprecated 2026-01: tiering centralised in triage-svc.

> Deprecated; see ADR-030.

## Notes

Changes to this decision need a new ADR reviewed by the Design Authority.
