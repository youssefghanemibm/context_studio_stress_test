# ADR-022: Retire SUBTRAK after Wave 1

- Status: Accepted
- Date: 2026-03-23
- Deciders: Freya Lindahl (Head of Recoveries & Subrogation), Elin Fosse (Lead Solution Architect)
- Forum: Design Authority
- Supersedes: none
- Superseded by: none

## Context

Subrogation cases move to recovery-svc with Wave 1, leaving the Subrogation Tracker (SUBTRAK) with no new work.

## Decision

Retire SUBTRAK once Wave 1 recoveries are stable in recovery-svc.

## Consequences

Target 2026-12-31.

## Notes

Changes to this decision need a new ADR reviewed by the Design Authority.
