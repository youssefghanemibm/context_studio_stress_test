# ADR-003: One PostgreSQL database per service

- Status: Accepted
- Date: 2025-02-17
- Deciders: Elin Fosse (Lead Solution Architect), Nadia Petrovic (Java Technical Lead)
- Forum: Design Authority
- Supersedes: none
- Superseded by: none

## Context

A shared database would couple the data models and release cycles of independent services.

## Decision

Each Claims Hub service owns exactly one PostgreSQL database; no other service reads or writes it.

## Consequences

No shared schemas; reporting via events and CDW.

## Notes

Implementation details live in the service repositories and are not repeated here.
