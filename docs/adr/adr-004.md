# ADR-004: Retain MQ for mainframe integration until CLARA decommissioning

- Status: Accepted
- Date: 2025-02-24
- Deciders: Marcus Oduya (Integration Architect), Henrik Vestergaard (Integration Platform Lead)
- Forum: Design Authority
- Supersedes: none
- Superseded by: none

## Context

CLARA's interfaces run over MQ Backbone. Rewriting them before CLARA is switched off would add risk for no lasting benefit.

## Decision

Keep MQ for every CLARA-facing interface until CLARA is decommissioned, and do not build new MQ flows from Claims Hub.

## Consequences

CLARA interfaces stay on MQ Backbone until 2027-09-30; no new MQ flows from Claims Hub.

## Notes

Questions about this decision go to the Design Authority agenda.
