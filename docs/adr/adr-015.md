# ADR-015: Region-wave data migration

- Status: Accepted
- Date: 2025-06-09
- Deciders: Callum Fairbairn (Data Migration Lead), Elin Fosse (Lead Solution Architect), Aisha Siddiqui (Claims Hub Product Owner)
- Forum: Design Authority
- Supersedes: none
- Superseded by: none

## Context

Migrating every claim at once would concentrate risk on one weekend.

## Decision

Migrate claims in waves by region and line of business.

## Consequences

Wave 0 Denmark, Wave 1 UK motor, Wave 2 the rest.

## Notes

Teams record follow-up work in the Claims Hub backlog and link it to this record.
