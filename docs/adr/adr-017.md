# ADR-017: Replace CDC with the batch bridge for reserve synchronisation

- Status: Accepted
- Date: 2025-10-21
- Deciders: Marcus Oduya (Integration Architect), Tomasz Wójcik (Enterprise Architect)
- Forum: Design Authority
- Supersedes: ADR-005
- Superseded by: none

## Context

CDC on the movement table misses reserve changes made by CLRGL090, which updates CLR.T_RESERVE directly (the reason ADR-005 failed).

## Decision

Synchronise reserves through the batch-to-event bridge (ADR-012) instead of CDC.

## Consequences

Supersedes ADR-005.

## Notes

Questions about this decision go to the Design Authority agenda.
