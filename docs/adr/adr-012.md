# ADR-012: Batch-to-event bridge for the reserve movement extract (CLX-IF-049)

- Status: Accepted
- Date: 2025-10-21
- Deciders: Marcus Oduya (Integration Architect), Henrik Vestergaard (Integration Platform Lead), Tomasz Wójcik (Enterprise Architect)
- Forum: Design Authority
- Supersedes: none
- Superseded by: none

## Context

Change data capture cannot see every reserve change in CLARA (see ADR-005), but the CLX-IF-042 extract already carries every movement record.

## Decision

Bridge the CLX-IF-042 records from MQ to Kafka (CLX-IF-049) and let reserve-engine consume them.

## Consequences

CLX-IF-042 records are republished to claims.reserve.movement.v1; reserve-engine consumes them for parallel run and Wave 2 sync.

## Notes

Implementation details live in the service repositories and are not repeated here.
