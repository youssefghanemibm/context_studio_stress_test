# ADR-005: Change data capture from DB2 for reserve synchronisation

- Status: Superseded
- Date: 2025-03-10
- Deciders: Marcus Oduya (Integration Architect), Derek Ollerton (DB2 Database Administrator)
- Forum: Design Authority
- Supersedes: none
- Superseded by: ADR-017

## Context

Claims Hub needs CLARA's reserve movements during the reserve parallel run and for later synchronisation.

## Decision

Capture changes from DB2 with change data capture on CLR.T_RESERVE_MOVEMENT.

## Consequences

Proposed CDC on CLR.T_RESERVE_MOVEMENT; superseded by ADR-017 because CLRGL090 updates bypass the movement table.

> This record is superseded by ADR-017 and is kept for history.

## Notes

Questions about this decision go to the Design Authority agenda.
