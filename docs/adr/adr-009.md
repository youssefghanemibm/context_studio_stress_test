# ADR-009: Store documents in DOCSTOR (now Evidence Vault) behind document-svc

- Status: Accepted
- Date: 2025-03-17
- Deciders: Elin Fosse (Lead Solution Architect), Tariq Hussain (Senior Java Developer)
- Forum: Design Authority
- Supersedes: none
- Superseded by: none

## Context

Claim documents are large binaries with their own retention rules.

## Decision

Keep document binaries in DOCSTOR (renamed Evidence Vault in November 2025) and expose only metadata through document-svc.

## Consequences

Binary content never stored in service databases.

## Notes

Implementation details live in the service repositories and are not repeated here.
