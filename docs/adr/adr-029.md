# ADR-029: API gateway rate limits for partner traffic

- Status: Accepted
- Date: 2026-04-20
- Deciders: Tomasz Wójcik (Enterprise Architect), Marcus Oduya (Integration Architect)
- Forum: Design Authority
- Supersedes: none
- Superseded by: none

## Context

Partner traffic from the Assessor Portal can spike and affect internal users.

## Decision

Apply API gateway rate limits to partner traffic.

## Consequences

Assessor Portal partners limited to 50 requests per second.

## Notes

Teams record follow-up work in the Claims Hub backlog and link it to this record.
