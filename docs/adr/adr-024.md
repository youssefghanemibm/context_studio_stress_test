# ADR-024: Observability stack and SLOs

- Status: Accepted
- Date: 2025-08-18
- Deciders: Elin Fosse (Lead Solution Architect), Neil Haworth (Head of Technology Delivery)
- Forum: Design Authority
- Supersedes: none
- Superseded by: none

## Context

Services need common dashboards, alerting and service-level objectives before go-live.

## Decision

Adopt one observability stack and define SLOs per service.

## Consequences

SLO 99.5% for claim-core-svc.

## Notes

Changes to this decision need a new ADR reviewed by the Design Authority.
