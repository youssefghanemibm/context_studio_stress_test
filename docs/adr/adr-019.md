# ADR-019: Rename reserve-svc to reserve-engine

- Status: Accepted
- Date: 2026-02-03
- Deciders: Tomasz Wójcik (Enterprise Architect), Daniel Achebe (Engineering Lead – Reserve & Finance Squad), Nadia Petrovic (Java Technical Lead)
- Forum: Design Authority
- Supersedes: none
- Superseded by: none

## Context

The reserve service had grown beyond simple CRUD: it runs Tier-3 review scheduling, indexation and currency revaluation.

## Decision

Rename reserve-svc to reserve-engine (CHUB-233), including the repository path, the Terraform module and the reserve change event.

## Consequences

Effective 2026-02-10: repo path services/reserve-engine, Terraform module reserve-engine, event reserve.changed.v2.
