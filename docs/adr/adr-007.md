# ADR-007: Terraform modules per service

- Status: Accepted
- Date: 2025-03-03
- Deciders: Nadia Petrovic (Java Technical Lead), Elin Fosse (Lead Solution Architect)
- Forum: Design Authority
- Supersedes: none
- Superseded by: none

## Context

Platform resources were being created by hand and drifted between environments.

## Decision

Describe each service's platform resources in its own Terraform module.

## Consequences

Module path infra/terraform/modules/<service>.

## Notes

Questions about this decision go to the Design Authority agenda.
