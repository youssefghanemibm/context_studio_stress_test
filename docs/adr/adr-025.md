# ADR-025: Masked data for migration rehearsals

- Status: Accepted
- Date: 2025-12-15
- Deciders: Callum Fairbairn (Data Migration Lead), Morag Duthie (Data Protection Officer)
- Forum: Design Authority
- Supersedes: none
- Superseded by: none

## Context

Migration rehearsals copy production claim data into non-production environments.

## Decision

Use masked data for every migration rehearsal.

## Consequences

Required by NISA Circular 2025/11 §4.

## Notes

Questions about this decision go to the Design Authority agenda.
