# ADR-023: Contract tests for all Kafka topics

- Status: Accepted
- Date: 2025-09-08
- Deciders: Nadia Petrovic (Java Technical Lead)
- Forum: Design Authority
- Supersedes: none
- Superseded by: none

## Context

Producers and consumers of Kafka topics are released independently, so schema changes can break consumers silently.

## Decision

Every Kafka topic has contract tests and a registered schema.

## Consequences

Schema registry compatibility BACKWARD.

## Notes

Changes to this decision need a new ADR reviewed by the Design Authority.
