# ADR-002: Kafka (Event Streaming Platform) as the Claims Hub event backbone

- Status: Accepted
- Date: 2025-02-17
- Deciders: Elin Fosse (Lead Solution Architect), Henrik Vestergaard (Integration Platform Lead), Tomasz Wójcik (Enterprise Architect)
- Forum: Design Authority
- Supersedes: none
- Superseded by: none

## Context

Claims Hub services must share domain events without point-to-point coupling, and the Integration Platform team already runs the Event Streaming Platform.

## Decision

Use Kafka on the Event Streaming Platform as the event backbone for every Claims Hub service.

## Consequences

All Claims Hub services publish domain events; topic naming <domain>.<event>.v<n>.

## Notes

Changes to this decision need a new ADR reviewed by the Design Authority.
