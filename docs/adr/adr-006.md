# ADR-006: OpenShift as the runtime platform

- Status: Accepted
- Date: 2025-02-24
- Deciders: Elin Fosse (Lead Solution Architect), Neil Haworth (Head of Technology Delivery)
- Forum: Design Authority
- Supersedes: none
- Superseded by: none

## Context

Claims Hub needs a container platform with a primary and a disaster-recovery site.

## Decision

Run all Claims Hub services on OpenShift.

## Consequences

Clusters ocp-prd-lon1 (primary) and ocp-dr-lds1 (DR).

## Notes

Questions about this decision go to the Design Authority agenda.
