# ADR-028: Use the reserve-engine revaluation run instead of CLRGL090 from Wave 2

- Status: Accepted
- Date: 2026-03-09
- Deciders: Daniel Achebe (Engineering Lead – Reserve & Finance Squad), Lena Kristiansen (Head of Reserving), Nadia Petrovic (Java Technical Lead)
- Forum: Design Authority
- Supersedes: none
- Superseded by: none

## Context

CLRGL090 revalues Nordic reserves without writing reserve movements, which left an audit gap (finding IA-25-07).

## Decision

From Wave 2 use the reserve-engine revaluation run instead of CLRGL090.

## Consequences

Revaluations post RV movements, closing audit finding IA-25-07 in the target.

## Notes

Implementation details live in the service repositories and are not repeated here.
