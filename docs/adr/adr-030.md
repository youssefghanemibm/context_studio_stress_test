# ADR-030: Shared tier library (ADR-018) replaced by triage-svc API

- Status: Accepted
- Date: 2026-01-19
- Deciders: Nadia Petrovic (Java Technical Lead), Sofie Bak (Engineering Lead – Intake & Triage Squad)
- Forum: Design Authority
- Supersedes: ADR-018
- Superseded by: none

## Context

The shared tier library (ADR-018) let services drift onto different library versions with different thresholds.

## Decision

Replace the shared library with the triage-svc API; tiering is centralised in triage-svc.

## Consequences

Supersedes ADR-018.

## Notes

Changes to this decision need a new ADR reviewed by the Design Authority.
